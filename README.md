# SimpleAuth Python 🔐

A lightweight authentication system written in Python that handles user registration and login using a local text-based database.

## ✨ Features
- **Email Validation:** Checks for basic email format.
- **Password Security:** Enforces a minimum length of 6 characters.
- **Persistent Storage:** Saves user credentials to a `database.txt` file.
- **Login Verification:** Validates user input against stored data.

## 🚀 How to Run
1. Ensure you have Python installed.
2. Download `auth_system.py`.
3. Run the script:
   ```bash
   python auth_system.py
